Theme library

Create a look for your aquarium. Themes hold colours, lighting and fish style—not fish, connection details, schedules or graphics budgets.

To use a theme, set theme_id in Home Assistant → Aquarium → Configuration, then Save + Restart. This page edits the library only; saving does not change the running aquarium.
