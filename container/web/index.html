Dashboard cards

Add the live aquarium to your Home Assistant dashboard. All cards show the same running Aquarium; they do not create another receiver.

  1. Install Ingress webpage card in HACS, then reload your Home Assistant browser page. If needed, add https://github.com/lovelylain/ha-addon-iframe-card as a custom Dashboard repository in HACS.
  2. Open this add-on's Info page in Settings → Apps/Add-ons. Copy its page URL or the full slug from it, including the repository prefix. This is not the aquarium Web UI / ingress URL.
  3. Paste it below. In your dashboard, choose Edit → Add card → Manual and paste the generated YAML.

Enter your installed add-on's slug to generate the cards.

Aquarium · view only

The aquarium display. Settings are managed in Home Assistant. A wide dashboard section works best.

Home Assistant OS / Supervisor and an administrator account are required for this route. The card manages ingress sessions using your HA login—do not paste tokens or temporary /api/hassio_ingress/… URLs. The view stream rejects input, but this does not give a user guest-only access to the add-on. The card is installed separately through HACS; this page does not change your dashboard or install anything.

Docker / HA Container users: use the built-in Webpage card with your configured authenticated HTTPS aquarium URL ending in /view/, not these Supervisor cards.
